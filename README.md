# ExamWiki — CST362 Flagship

A premium, interactive study guide for **CST362 Programming in Python**. Designed for KTU B.Tech students to master the syllabus through a high-end, responsive interface.

## ✨ Features

- **2-Column Layout**: Effortless navigation with a persistent sidebar and a focused content well.
- **Full Notes**: Comprehensive coverage of all 5 modules, optimized for exam preparation.
- **⌘K Command Palette**: Lightning-fast search to find any topic instantly across the entire syllabus.
- **Dynamic Theme**: Supports both Light and Dark modes with persistent user preference.
- **Reading Progress**: Visual progress bar and breadcrumb tracking as you study.
- **Code Polish**: Beautifully formatted Python code blocks with one-click copy functionality.

## 🚀 Getting Started

This is a standalone frontend application. No complex setup or dependencies are required.

1.  Clone this repository.
2.  Open `index.html` in any modern web browser.

## 🛠️ Built With

- **HTML5/CSS3**: Semantic structure and custom CSS variables for theming.
- **Vanilla JavaScript**: High-performance, dependency-free logic.
- **DM Sans & Instrument Serif**: Premium typography for maximum readability.
